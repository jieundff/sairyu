## 접근 방식

### 1단계 — 데이터 준비
- 01–05 영상 재다운로드 (Q1-A면 17개 전부)
- `pip install mediapipe openai-whisper opencv-python matplotlib`
- 01번: 가로 영상이라 앉는 구간에서 회전 보정. 프레임별 포즈 검출 신뢰도가 낮으면 90° 회전본으로 다시 검출해서 더 나은 쪽을 채택

### 2단계 — 구간 분할
- Whisper medium(ko)으로 전사한 뒤, 진행자 프롬프트 키워드로 P1–P6 시작 시점 탐지
  - P1 "입어주시면" / P2 "비에 젖지" / P3 "햇빛·햇살" / P4 "더위" / P5 "앉아서·편안한" / P6 "벗어주시면"

### 3단계 — 포즈 분석 (`ut-analysis/pose.py`)
- MediaPipe Pose Landmarker heavy, 10 fps
- 계산 항목
  - 무릎각, 고관절각(몸통-허벅지, world 좌표)
  - 몸통 기울기(영상 수직 대비)
  - 손목 영역: 머리 / 목·가슴 / 배·허리 / 아래 / 가림(visibility<0.5)
- 코드 규칙: 헤더 범례 그대로 적용 (H > C2 > C1 > W > N, T, S1, S2) + 1초 다수결 평활화

```python
# 예시: 착석 판정
seated = knee < 120 and hip < 135
code = "S2" if seated and (tilt >= 25 or legs_extended) else ("S1" if seated else ...)
```

### 4단계 — 산출물 생성
- 셀 이미지: 구간 40%·85% 프레임 + 스켈레톤 오버레이 (기존과 같은 흰 선 + 노란 손목 점), 366×649 비율
- 셀 텍스트: `t xx.xs · 코드`, 무릎·고관절·기울기, 손 L·R, 포즈 코드 누적
- 표: 14개 지표
- 타임라인 PNG: 기존과 같은 matplotlib 레이아웃 (3352×893 비율)

### 5단계 — 피그마 반영
- 작업 전 기존 3개 프레임을 복제해 백업
- 매트릭스
  - `Col headers`에 P01–P05 헤더 추가 (기존 헤더 복제 후 텍스트 교체)
  - 각 Row에 셀 추가: 기존 셀을 복제하고, 카드는 같은 컴포넌트 인스턴스로 만든 뒤 텍스트·이미지 교체
- 표: 기존 행을 복제해 P01–P05 행 추가
- 타임라인: 기존 이미지 노드를 복제해 P01–P05 추가
- 헤더 문구 수정: "영상 12개(06–17 …" → "영상 17개(01–17 …, 01은 1920×1080 가로)"
- 겹침 방지를 위해 주변 프레임 이동 (Q3-A 기준)
